### 简介
用来学习Unity开发的练习项目，模仿自土豆兄弟。  
**注：Unity版本已升级至Unity6，旧版本无法正常运行。**
### Unity版本  
6000.0.30f1
### 运行
双击Assets\Scenes下的Start场景，开始运行。
